How to get a fresh nonce
  1. Open the BountyBook nonce endpoint in a normal browser tab.
  2. Copy the nonce value from the JSON.
  3. Paste it above and tap “Use this message”, then sign with the wallet.
  4. Reply on the Forgejo issue with the message and the signature so the agent can call /auth/verify and submit.
Nonces can expire; if verification fails, fetch a fresh nonce and sign again.
